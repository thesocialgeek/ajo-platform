# Ajo 2.0

Public website for Ajo 2.0.

## Architecture
- GitHub repository: public frontend code
- Supabase: private application database and future authentication/admin data
- Never commit service-role keys, passwords, KYC documents, member payment records or other secrets to this repository.

## Current features
- Ajo by Amount and Ajo by Goal
- Find My Ajo helper
- Preferred collection date and position requests
- Live application submission to Supabase
- Published testimonials pulled from Supabase only when permission is confirmed
- Responsive mobile design

## Important
A preferred collection date is a request, not a confirmed position. Group and collection placement must be approved before confirmation.
